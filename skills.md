# Project Skills

All skills live in `.opencode/skills/` and are available to agents working in this codebase.

## Design & UX

- **frontend-design** - Guidance for distinctive, intentional visual design when building new UI or reshaping existing ones. Helps with aesthetic direction, typography, and avoiding templated defaults.
- **impeccable** - Design, critique, audit, polish, optimize, animate, or otherwise improve a frontend interface (websites, dashboards, product UI, forms). Covers UX review, visual hierarchy, accessibility, theming, typography, motion, and reusable design systems. Not for backend-only tasks.
- **microinteractions** - Design the small details - triggers, rules, feedback, loops and modes - that make interfaces feel responsive: button feedback, loading states, toggles, form validation responses, progress indicators.
- **review-animations** - Reviews animation and motion code against a high craft bar (Emil Kowalski's design engineering philosophy). Defaults to flagging; approval is earned.
- **web-typography** - Select, pair, and implement typefaces for web projects. Covers font pairing, line height, responsive typography, font loading, type hierarchy, variable fonts, FOUT/FOIT, and readability.
- **improve-animations** - Surveys a codebase's animation and motion code as a senior motion advisor, then produces a prioritized audit and self-contained implementation plans for other agents to execute. Read-only; it plans, it does not apply.

## Animation (GSAP)

- **gsap-core** - The core GSAP API: `gsap.to()`, `from()`, `fromTo()`, easing, duration, stagger, defaults, `gsap.matchMedia()` (responsive, prefers-reduced-motion).
- **gsap-react** - GSAP in React/Next.js: the `useGSAP` hook, refs, `gsap.context()`, and cleanup on unmount.
- **gsap-scrolltrigger** - ScrollTrigger: scroll-linked animations, pinning, scrub, triggers, parallax.
- **gsap-timeline** - Sequencing animations with `gsap.timeline()`, the position parameter, nesting, and playback.
- **gsap-plugins** - GSAP plugins and registration: ScrollToPlugin, ScrollSmoother, Flip, Draggable, Inertia, Observer, SplitText, ScrambleText, SVG/physics plugins, CustomEase, EasePack.
- **gsap-performance** - Animation performance: prefer transforms, avoid layout thrashing, will-change, batching, smooth 60fps.
- **gsap-utils** - `gsap.utils` helpers: clamp, mapRange, normalize, interpolate, random, snap, toArray, wrap, pipe.
- **gsap-frameworks** - GSAP in Vue, Svelte, and other non-React frameworks: lifecycle, scoping selectors, cleanup. For React use **gsap-react**.
